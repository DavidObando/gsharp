# A Tour of G#

Get a feel for G# through small programs and focused explanations. Read in order for an introduction, or choose the chapter that answers your question.

The Tour is a reading guide with code you can run locally, not an online execution service. Start with [installation](../getting-started/install.md) and [your first program](../getting-started/quickstart.md) if you want to try each example.

## Chapters

| Chapter | What you will learn |
| --- | --- |
| [1. Basics](basics.md) | Variables, functions, primitive types, and printing values. |
| [2. Types and values](types.md) | Data models, classes, collections, and nullable values. |
| [3. Control flow](control-flow.md) | Conditions, loops, nullable bindings, and pattern matching. |
| [4. Concurrency](concurrency.md) | Structured scopes, async functions, and asynchronous sequences. |
| [5. .NET interop](dotnet-interop.md) | Imports, library types, LINQ, delegates, events, and native interop. |

Each chapter links to the language guide or reference when you need more detail. The examples follow the documentation version selected in the header.
